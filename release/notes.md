# v3.34.0

> [!IMPORTANT]
> 升级或重启后，不兼容插件将保持未启动，其额外认证、拦截及其他能力不再生效，宿主原生认证继续执行
> 升级前请核对已安装插件的宿主版本范围和能力版本；启用配置、绑定、密钥与私有数据会保留

## 插件兼容与模型目录

- 宿主启动、更新和回滚统一检查插件兼容性；版本不兼容时显示未启动状态及原因，可在插件详情确认风险后尝试本次启动，下次宿主启动重新检查；包损坏、清单或 RPC 格式不兼容、平台不符不能通过确认绕过
- 新增 `model_catalog` v2，插件可为受管上游适配器发布独立模型及客户端画像，无需原生目录存在同名模型；目录可见范围与执行账号按适配器账号、Key 权限及模型政策共同限定，原有 v1 别名能力继续可用
- 修复路由收窄账号范围后，执行选号仍使用原始范围的问题；旧会话亲和与 429 换号遵循当前候选范围，避免选中不具备所需模型或工具能力的账号
- Codex 模型目录保留完整原生对象，并追加可见的适配模型；成功读取但被账号模型政策全部过滤的 API Key 目录返回空列表，不再误报目录读取失败

## 上游重试与计价

- 修复适配插件收到单次受管推理 HTTP 429 后无法进入账号迁移判断的问题；仅在没有业务输出、续接材料或其他调用等条件下提供重放依据，仍受现有重试预算与安全检查约束，不扩展到 WebSocket 或 HTTP 200 流内错误
- 修复插件 RPC 流结束和会话失败时的资源撤销竞态，确保回调撤销与发送观测封存完成后再判断是否可重试
- 补充 GPT-6.1 Terra 的内置标准、Flex、Priority 和长上下文价格，以及预览版网页搜索计费分类

## 管理端搜索与界面

- 账号名称和邮箱、Key 名称和标签、用量记录及运维错误的搜索改为字面量包含匹配，输入 `%`、`_` 和 `\` 时按普通字符处理；账号列表搜索范围统一为名称与邮箱
- 账号批量编辑、导出和删除收纳到更多操作菜单；简化账号组筛选，调整用量页日期与平台控件在窄屏下的排列
- 额度窗口按各自剩余比例显示颜色：不足 30% 时警示，不足 10% 时显示危险状态

## 平台与依赖

- 修复数据库备份暂存文件使用 Unix 专用接口导致的 Windows 编译失败，Unix 文件权限保持不变
- 更新 Zstd 的 Rust 安全封装依赖，保留底层 Zstd 1.5.7 与既有压缩级别
