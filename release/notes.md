# v3.31.2

## 表单与设置

- API Key 名称、额度和并发等字段接入表单校验，错误持续显示在对应字段下方，提交失败时自动滚动并聚焦首个错误字段
- 错误提示显示时保持表单高度稳定，修复恢复探测模型标签误触发旁边复选框的问题
- 设置及备份配置存在未保存修改时，离开页面前提供确认，减少误操作造成的草稿丢失

## 交互与显示

- 补齐移动侧栏的初始焦点、Tab 循环、Esc 关闭及焦点恢复，账号搜索补充可访问名称
- 收紧没有正文的确认弹窗留白，未保存设置的离开按钮简化为“放弃并离开”
- 账号状态与请求记录推理强度居中显示，收窄表格默认单元格左右内边距，精简活跃账号用量文案
- 统一首页与用量图表提示中的时间字体和下方间距，日期选择浮层与输入框保留更清楚的间隔
- 修复窗口重新激活时意外打开悬停浮层，以及紧凑行高下单行省略文本的纵向裁切

## 主题配置

- 减少进入主题配置时的同步计算，折叠的变量列表在展开后渲染，完整预览异步加载
- 管理端升级至 UI 组件库 v0.7.0
