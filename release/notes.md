# v3.35.1

## 连接稳定性

- 修复 Responses WebSocket 慢速上传大消息时被心跳误判为失联的问题，探活包含实际收包进度，避免 Codex 在上传期间断开并反复重连；停传且不响应心跳的连接仍会超时回收
- OpenAI 会话亲和存储操作的等待预算由 100 毫秒调整为 500 毫秒，减少短暂存储或调度抖动导致的会话绑定失败

## 错误处理

- 客户端版本门禁拒绝改为返回 `400 Bad Request`，保留 `client_version_too_old` 和 `client_version_unavailable` 错误码，避免版本不符合要求时触发无效重试
- 隐私规则拒绝请求时返回明确的 `privacy_policy_rejected` 错误；修正 xAI 流式响应中的错误类型识别，避免将事件类型用于上游错误分类
- 统一管理接口的中文错误提示与模型 API 的英文错误提示，细化 API Key 参数校验及每日、每周费用限制的说明
- 系统更新与语音连接失败区分客户端提示和内部诊断，减少底层连接细节外露；系统更新失败保留原因链并记录运维诊断，便于排查
