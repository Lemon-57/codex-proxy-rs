# v3.31.1

## 插件与请求记录

- 移除 `provider_parameters` 和 `installation_id` 专用构造入口，身份生成、持久化及关联字段改写统一由插件通过现有 `request` / `attempt` / `outbound` 链路完成；原生默认身份处理保留
- 移除上游返回模型的采集、存储写入、接口字段和界面展示，保留请求模型、映射后模型以及原始上游响应透传
- 本次不新增数据库迁移，旧请求记录沿用现有保留策略清理

## 界面优化

- 更新 UI 组件库至 v0.6.1，增强排序箭头的方向区分，保持原有尺寸和表头文字颜色
- 分页按钮随页码长度扩宽，按容器实际宽度调整可见页码；单行空间不足时隐藏每页条数选择框，保留翻页按钮与当前页码
- 折叠侧栏的悬停提示延迟至约 800 毫秒显示，语言切换的加载状态移至右侧勾选位置，保留国旗
- 统一使用统计、请求记录及英文 Analytics、Request log 文案，精简模型筛选输入并收窄模型列
- 修复请求健康卡片加载时显示临时统计粒度的问题，统一账号额度时间窗口标签

## 构建与部署

- 更新 Node.js 构建镜像以及 PostgreSQL、Redis 镜像固定版本，调整 CI 运行环境并修复 Ubuntu 26.04 下的备份测试探针
